Como usar, passo a passo

  1. Contrate o mínimo

    • OpenAI Plus + Anthropic Pro (€40). Suba para €100 só no provedor em que bater o limite.
    • Empresa: use plano Team/Enterprise/API, não conta pessoal.

  2. Prepare o projeto (uma vez)

    • Pre‑commit com lint e formatação:
    terminal
    pnpm add -D husky
    • Crie style-guide/style-guide.md: stack alvo e regras Faça / Deveria / Não faça. É o arquivo de maior efeito.
    • Crie AGENTS.md (veja “Regras” abaixo).
    • Um arquivo fino por ferramenta (.cursorrules, .clinerules, .gemini/GEMINI.md, .github/copilot-instructions.md) apontando para o AGENTS.md.

  3. Bloqueie segredos

    .claude/settings.json
    {
  "permissions": {
    "deny": ["Read(./.env)", "Read(./.env.*)", "Read(*.pem)", "Read(*.key)", "Read(./src/environments/**)"]
  }
}

  4. Conecte o MCP do Angular CLI

    Detalhes na seção MCP abaixo. Arquivo .mcp.json na raiz, registrado uma vez para todos os agentes.

  5. Fluxo por tarefa

    1. Planeje com Fable (medium): objetivo, restrições, critério de pronto.
    2. Implemente com Sol (ou GLM Flash se for mecânico), thread nova por tarefa.
    3. Verifique em ordem do mais barato ao mais caro: ng lint → ng build → testes → E2E (Playwright).
    4. Revise o diff linha a linha. Peça segunda opinião a outro modelo.
    5. Commit. Se o agente errou de novo no mesmo ponto, corrija o AGENTS.md, não só o prompt.

  6. Delegação: Fable pensa, Sol digita

    .claude/agents/gpt-implementer.md
    ---
name: gpt-implementer
description: Delegates well-specified implementation tasks to GPT-5.6 Sol via the Codex CLI. Use for mechanical, clearly spec'd legwork, not for architecture or design decisions.
tools: Bash, Read, Grep, Glob
---
You are a thin wrapper around the Codex CLI. Take the task you were given, write it into a single self-contained prompt (all relevant file paths, constraints, and acceptance criteria included, Codex starts with zero conversation context), then run:
codex exec -m gpt-5.6-sol "<your prompt>"
Return Codex's output as your result. Do not implement anything yourself.

  7. Contexto de 1M no Codex (opcional)

    ~/.codex/config.toml (antes de qualquer [seção])
    model = "gpt-5.6-sol"
model_context_window = 1000000
model_auto_compact_token_limit = 900000
    uso pontual, sem alterar o padrão
    codex -m gpt-5.6-sol \
  -c model_context_window=1000000 \
  -c model_auto_compact_token_limit=900000

  8. Skills para o que se repete

    • Pasta .agents/skills/<nome>/SKILL.md (lida por Codex, Cursor e Claude Code).
    • Skills globais: copie para ~/.claude/skills/.
    SKILL.md
    ---
name: ng-refactor
description: Moderniza um componente legado em passos com checkpoint humano. Use quando o usuário pedir "refatore", "modernize" ou "migre para signals" em um componente.
---
## Passos
1. Analisar  2. Limpar  3. Atualizar  4. Modernizar  5. Tipar  6. Refatorar  7. Revisar
Pare após cada passo e peça aprovação.
    • Descrição = “o que faz + quando usar”, com as frases que você digitaria. Corpo < 500 linhas; detalhe em references/.
    • Codifique processo, não conhecimento. Copie só as skills que o projeto usa.

  9. Teste na sua base antes de decidir

    Rode as mesmas 5 tarefas em Codex, Claude e Cursor. Compare diff, passos de correção e limites atingidos:

    • Migrar componente para input()/output() e @if/@for
    • Testes de um serviço com dependências
    • Code review de um PR real
    • Rebase de uma branch com vários conflitos
    • Bug descrito como “comportamento atual” e “esperado”

Regras prontas

AGENTS.md: regras de comportamento

AGENTS.md
## Workflow
- Preserve my edits. Check a file's current state before changing it; do not revert or drop my changes or comments.
- Keep fixes local. Change the minimum needed. No opportunistic refactors; suggest them instead.
- Stay in your lane. Do not touch unrelated files; prefer minimal diffs.
- Run lint and the relevant tests before declaring a task done.
- Never start the dev server (ng serve); one is usually running on :4200.
